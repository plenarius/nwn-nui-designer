NUI Designer is a visual editor for Neverwinter Nights: Enhanced Edition's NUI windows: the JSON windows a script opens with NuiCreate or NuiCreateFromResRef (not the older .gui files).
 
I started it for Layonara's own windows and it grew into something I hope other builders find handy. It's a desktop app for Windows, macOS and Linux, and it reads your game and hak files where they already are. Nothing is uploaded anywhere; the only thing it asks the internet is whether there's a newer version. If you'd rather run it from the source code in your browser, that still works exactly as before.
 
WHAT IT DOES
 
Window editor
- Build a window from every element nw_inc_nui.nss can make.
- It's laid out and drawn the way the client does it (checked against build 8193.37), with your game's skin and fonts when it finds your install.
- Problems are listed as you work: clipped text, rows that don't fit, sizes the client refuses, missing images, unknown keys.
- Multi-select, match size, align and distribute. NUI has no free positioning, so these work through sizes and spacers, and it tells you plainly when something can't be done.
- Export as a .jui (for NuiCreateFromResRef) or as NWScript that builds the same window.
 
Your own house style
- Write your server's UI rules in a small JSON file: row heights, allowed gaps, colour palette, tooltip length, fixed-size windows and more, with exemptions per window.
- The editor checks every window against it as you work, and the same check runs from the command line, so it can fail a pull request in CI.
- Layonara's own rules ship as a worked example.
 
Skin and font editor
- Restyle every NUI window in your module through nui_skin.tml: frames, buttons, scrollbars, colours and fonts.
- Every key is checked the way the client reads it.
- Export the skin as a hak.
- Five open skins are built in to start from: Ink and brass, Bronze, Brass and soot, Verdigris and paper, Oxblood and rivets.
 
Full theme export
- Recolour the original GUI to match your skin, so the whole interface comes out as one package, ready for a hak.
 
Command line
- Check windows in CI (with GitHub annotations), draw windows to PNG, check a skin, pack a hak.
 
GETTING STARTED
 
Download the app for your system from the files on this page, or from the latest release on GitHub:
 
- Windows 10 and 11: the setup .exe. It installs just for you, no administrator needed.
- macOS 12 or later (Apple silicon and Intel): the .zip here, or the .dmg on GitHub. Move the app to Applications.
- Linux: the AppImage (here on the Vault it's inside a .7z, so extract it first). Make it executable and run it. You can check it against SHA256SUMS in the GitHub release.
 
https://github.com/plenarius/nwn-nui-designer/releases/latest
 
If NWN:EE is installed through Steam, GOG or the Beamdog client, it finds it and draws with the game's own look. Without the game it uses its own open skin, so it works anywhere. When a new version comes out, the app asks before downloading anything.
 
Prefer running it from source? You need Node.js 24 and pnpm (run "corepack enable" once).
 
  git clone https://github.com/plenarius/nwn-nui-designer.git
  cd nwn-nui-designer
  pnpm install
  pnpm dev
 
Then open http://localhost:5173. It's the same editor, with the same settings and the same game detection.
 
KNOWN LIMITS
 
It draws widgets at rest (no hover or pressed states on the canvas), doesn't draw tooltips, and treats sliders, the colour picker and charts as simple stand-ins. The full list, with reasons, is in docs/GAPS.md.
 
FEEDBACK
 
It's very much a work in progress. If a window looks different in the designer than in the game, there's an issue form just for that ("Draws differently") on GitHub, and those reports are the most useful thing you can send me.
